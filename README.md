# 🏝️ Island Sprinters

A 2D platformer game developed using **Unity and C#**, featuring island-themed levels, platform-based movement, shooting mechanics, enemies, and teleportation portals.

## 🎮 Project Overview

Island Sprinters is a 2D platformer where players explore multiple levels, navigate through platforms, dodge enemies, and use shooting mechanics to overcome challenges. Players can perform single and double jumps, use bounce objects to gain extra height, and travel between locations through animated teleportation portals.

## ✨ Features

- **Multiple Levels:** Explore different levels with platforming challenges.
- **Player Movement:** Move the character left and right through the environment.
- **Single & Double Jump:** Jump between platforms and perform a second jump while airborne.
- **Bounce Boost:** Certain objects provide an extra upward boost when the player jumps on them.
- **Moving Platforms:** Navigate levels using platforms that move through the environment.
- **Shooting Mechanics:** Use a simple gun and bullet system to shoot.
- **Enemy Encounters:** Dodge enemies while navigating through levels.
- **Teleportation Portals:** Use animated portals to instantly teleport between locations.
- **Pixel Art Visuals:** Features a pixel-art visual style.
- **8-Bit Sound Effects:** Includes classic 8-bit sound effects.

## 🕹️ How to Play

1. Download and extract the game ZIP file from the Releases section.
2. Open `index.html` in a web browser to launch the game.
3. Move left and right to navigate through the levels.
4. Jump and use the double jump to reach higher platforms.
5. Use bounce objects to gain additional jump height.
6. Navigate moving platforms and avoid enemies.
7. Use shooting mechanics to overcome challenges.
8. Use teleportation portals to travel between locations.
9. Progress through the levels and aim for the highest score.
