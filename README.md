# 🏝️ Island Sprinters

A 2D platformer game developed using **Unity and C#**, featuring island-themed levels, ball-based character movement, shooting mechanics, and animated teleportation portals.

## 🎮 Project Overview

Island Sprinters is a 2D platformer where players explore multiple levels, navigate through platforms, dodge enemies, and use shooting mechanics to overcome challenges. The game features ball-based character movement and animated portals that allow instant teleportation between locations.

## ✨ Features

- **Multiple Levels:** Explore different levels with platforming challenges.
- **Ball-Based Movement:** Control the character using ball-based movement mechanics.
- **Shooting Mechanics:** Use a simple gun and bullet system to shoot.
- **Enemy Encounters:** Dodge enemies while navigating through levels.
- **Teleportation Portals:** Use animated portals to instantly teleport between locations.
- **Pixel Art Visuals:** Features a pixel-art visual style.
- **8-Bit Sound Effects:** Includes classic 8-bit sound effects.

## 🕹️ How to Play

1. Download and extract the game ZIP file from the Releases section.
2. Open `index.html` in a web browser to launch the game.
3. Navigate through the platforms and explore the levels.
4. Avoid enemies and use the shooting mechanics to overcome challenges.
5. Use portals to teleport between locations.
6. Progress through the levels and aim for the highest score.
